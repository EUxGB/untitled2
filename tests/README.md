# Автотесты Söyle

81 проверка логики + 6 проверок настоящих микрофона, записи и воспроизведения (`tests/real-media.test.js`, страница по http://localhost, микрофон — файл `tests/voice.wav`): пары и фразы, записи носителей, игра, интервальные повторения, «На слух»,
свободная речь (в том числе поведение на Android), запись и сравнение, стабильность кнопок,
доступность WCAG 2.1 AA (axe-core) в светлой и тёмной теме.

```bash
npm install
npx playwright install chromium
npm test
```

Распознавание речи, микрофон, синтез и сеть подменяются заглушками — тесты проверяют логику тренажёра,
а не качество распознавания Google.
