  «stale-while-revalidate для HTML» НЕ взят: так старая версия застревает у пользователя (ровно то, из-за чего в CLAUDE.md был запрет на service worker).

## Объём (замер 2026-10-21 по файлам репозитория)
index.html 1,0 МБ · шрифт Onest 0,08 МБ · записи Common Voice `audio/cv` 3,1 МБ · озвучка Piper `tts/` 12,0 МБ (1 251 файл, ветка `tts-audio`) · значки 0,1 МБ.
Итого ≈ 16 МБ.

## Решения
1. `sw.js` в корне сайта, номер сборки подставляет публикация (как в index.html).
2. Страница (переход, `index.html`, `./`) и списки (`manifest.json`, `tts/manifest.json`, `audio/cv/index.json`) — **сначала сеть**: новая версия приходит
   сразу, без сети — сохранённая копия. Ключ страницы — без `?v=` (кнопка «Обновить приложение» добавляет его).
3. Шрифты, записи, озвучка, значки — **сначала кэш** (имена у озвучки — хэш текста, у записей — номер; не меняются).
4. Основа (страница, шрифты, списки, значки, ≈ 1,2 МБ) сохраняется при установке service worker; записи и озвучка (≈ 15 МБ) — кнопкой
   «Скачать для офлайна» в «Прогрессе» (раздел «Без интернета»), с ходом «N из M» и итогом; повторное нажатие докачивает недостающее.
   После скачивания — `navigator.storage.persist()` (просьба браузеру не стирать).
5. Регистрация — только на своём домене (`simitci.ru`) и в тестах (`window.__sw`); на githack — нет (там кэш и так бывает старым).
6. Состояние скачивания — `soyle-offline` (в `BK_DEVICE_KEYS`: к устройству, в резервную копию не идёт).

## Что без сети не работает (честно сказать в разделе)
- Оценка произношения: распознавание речи Chrome на Android идёт через серверы Google (вариант на устройстве — только для компьютера,
  blink-dev «Intent to Ship: On-device Web Speech API»). Слушать, читать, записывать себя — можно.
- Примеры и записи из Tatoeba и Wikimedia, перевод MyMemory, видео YouGlish, «Соседи». Отзывы копятся в очереди (уже есть).

## Ревью отдельным агентом (2026-10-22) — что исправлено
- Переход на страницы сайта (`frazy/…`) подменял сохранённое приложение (любая навигация писалась в ключ `index.html`) → страница приложения = только адрес приложения и `index.html` рядом.
- Записи Common Voice названы по порядку (001.mp3…), при пересборке номера раздаются заново → новый `audio/cv/index.json` сбрасывает сохранённые записи, раздел предлагает докачать.
- `<audio>` шлёт Range (Safari ждёт 206) → ответ 206 из сохранённого файла; 206 в кэш не кладётся.
- Лишнее после скачивания удаляется; «Сохранено» сверяется с тем, что реально в кэше; на iPhone — пояснение про разные хранилища Safari и приложения.
- Страница ждёт сеть не дольше 4 с, потом — копия.
- Найдено тестом: при обычном проигрывании запись не сохранялась (поздний `clone()`), исправлено.
- Тесты: Playwright `setOffline` не действует на запросы service worker — тестовый сервер «выключается» сам (обрывает соединения) и не даёт HTTP-кэша.

## Откат (если service worker мешает)
Удалить регистрацию из `index.html` мало — у пользователей он останется. Заменить содержимое `sw.js` на:
```js
self.addEventListener("install", () => self.skipWaiting());
self.addEventListener("activate", e => e.waitUntil(caches.keys().then(ks => Promise.all(ks.map(k => caches.delete(k))))
  .then(() => self.registration.unregister()).then(() => self.clients.matchAll()).then(cs => cs.forEach(c => c.navigate(c.url)))));
```
и опубликовать (файл `sw.js` оставить на сайте).
