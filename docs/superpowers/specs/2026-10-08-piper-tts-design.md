# Озвучка Piper вместо синтеза телефона — дизайн (2026-10-08)

Решения пользователя: «Синтез речи ужасный» (08:48); сравнение на слух невозможно (с телефона) → объективная проверка;
«Вариант 1» (15:26) — озвучка заранее, автоматически при публикации; «Вариант А» (17:50) — Piper озвучивает всё, включая собеседников в городе.

## Почему Piper (проверено, ветка `tts-samples`, `asr.md`)
Whisper large-v3 распознал 9 клипов (5 слов, 4 фразы) каждого голоса; доля верных букв: Piper tr_TR-dfki-medium 100 % (9/9 без ошибки),
носитель 100 % (контроль), XTTS по голосу CV 87 %, XTTS встроенный 79 %, F5-TTS-Turkish 61 %, MMS 57 %. Мерилась разборчивость, не естественность.
Ограничение: у Piper один турецкий голос; датасет голоса — CC BY-NC-SA 4.0 (карточка модели) → только некоммерческое использование, с указанием авторства.

## Что озвучивается
Всё, что сайт может произнести синтезом (счёт 2026-10-08): 394 фразы, ~800 слов (439 словарных + 504 словоформы, пересекаются),
696 реплик города, числа/цены города, слова уроков. Оценка — 2 300–2 500 файлов, 20–25 МБ (по ~8 КБ на клип). Записи носителей остаются первыми.
Не озвучивается: свободный текст пользователя («Свободно», «мои фразы») — остаётся голос телефона.

## Устройство
1. **Список текстов** `tests/tts-texts.js` (Playwright, как `city-phrases-dump.js`): статический обход данных сайта + перечисление
   динамических реплик (числа, «X, tamam. Başka?»). Тест: всё, что произносится во время тестов (`window.__spoken`), есть в списке.
2. **Хранение**: ветка `tts-audio` (не `main`): `tts/<hash>.mp3` + `tts/manifest.json` {нормализованный текст → файл}. Имя файла — хэш
   нормализованного текста и версии голоса: правка текста → новый файл, неиспользуемые удаляются.
3. **Генерация в CI** (`tests.yml`, задача перед `deploy`): берёт ветку `tts-audio`, озвучивает Piper только недостающее, Whisper проверяет
   новые клипы; не прошедшие проверку в манифест не попадают (на сайте — голос телефона) и пишутся в отчёт. Первая полная озвучка —
   разовый запуск (оценка 1–3 ч, не замерено).
4. **Сайт**: одна функция `speakTr(text, opts)` вместо четырёх мест синтеза (`sayText`, запасной синтез `playReference`, `npcSay`,
   кнопка «Синтез»): запись носителя → файл Piper → голос телефона. Скорость (Kulak) — `playbackRate` с `preservesPitch`.
   Разные персонажи — один голос Piper (решение А).
5. **Публикация** копирует `tts/` из ветки в артефакт Pages рядом с `index.html` (лимиты Pages: сайт ≤ 1 ГБ, трафик ~100 ГБ/мес).
6. **Тесты**: подбор файла по тексту, запасной голос, скорость; CI — покрытие списка; `verify` — 20 случайных файлов отдаются сайтом.
7. **Лицензия** — строка в «Как пользоваться».

## Риски
Первая озвучка долгая; один голос на всех; некоммерческая лицензия; Whisper ловит неразборчивость, но не интонацию;
публикация дольше на время озвучки новых текстов.
